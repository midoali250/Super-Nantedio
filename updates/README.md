# مركز معلومات تحديثات الألعاب

هذا المجلد هو المكان الموحد لمعلومات إصدارات ألعاب bitvault-engine. كل لعبة
لها ملف مستقل داخل `games/`، وملف الـ APK نفسه يُرفع إلى GitHub Releases،
وليس داخل هذا المجلد.

**الموجود الآن بيانات إصدارات فقط، وليس نظام تحديث تلقائي جاهزًا.** إصدار
ماريو 1.2 الحالي لا يقرأ الملفات هنا ولا يُظهر إشعارات أو زر تحديث منها.
لازم نضيف عميل تحديث لكل لعبة مستقبلًا عشان تتحقق من الملف وتعرض إشعارًا
وزر التحميل، ثم يوافق المستخدم على تثبيت تحديث أندرويد.

## الألعاب المسجّلة

| اللعبة | ملف بيانات التحديث | الحزمة |
| --- | --- | --- |
| ماريو + داك هانت | [`games/nes-mario-duckhunt.json`](games/nes-mario-duckhunt.json) | `com.midoali.nes` |

الرابط الثابت الذي سيقرأه عميل اللعبة مستقبلًا:
`https://raw.githubusercontent.com/midoali250/bitvault-engine/main/updates/games/nes-mario-duckhunt.json`

## إضافة تحديث

1. ابنِ APK جديدًا بنفس `package_name` وارفع `version_code` عن الإصدار السابق.
2. وقّع APK بنفس مفتاح توقيع الإصدار المثبت؛ إذا تغير المفتاح فلن يقبله أندرويد
   كتحديث فوق النسخة السابقة. مفتاح التوقيع القديم لماريو حُذف محليًا أثناء
   التنظيف، لذا يلزم استعادته من نسخة احتياطية لتحديث 1.2 فوقه.
3. أنشئ GitHub Release وارفع الـ APK إليه، واختبر رابط التحميل المباشر.
4. حدّث ملف اللعبة: `version_code` و`version_name` والرابط والحجم وSHA-256
   وتاريخ النشر وملاحظات الإصدار. لا ترفع أي مفاتيح خاصة أو رموز وصول هنا.
5. شغّل `python3 tools/validate_updates.py --check-downloads` ثم ارفع التعديل.

لإضافة لعبة جديدة، انسخ ملف ماريو إلى اسم مناسب في `games/`، واجعل `game_id`
مطابقًا لاسم الملف واستخدم اسم حزمة خاصًا بها. راجع نتائج GitHub Actions.

## الحقول

`schema_version` ثابت حاليًا على 1. `game_id` معرف ثابت للعبة؛ `game_name`
اسمها؛ `package_name` اسم حزمة أندرويد؛ `version_code` رقم صحيح يزيد مع كل
إصدار؛ `version_name` الاسم الظاهر؛ `min_android_sdk` أقل API؛ `apk_url`
رابط APK المباشر؛ `apk_sha256` بصمة الملف؛ `apk_size_bytes` حجمه؛
`release_url` صفحة الإصدار؛ `published_at` وقت UTC بصيغة ISO 8601؛
`release_notes_ar` ملخص التغييرات؛ `required` يبيّن إن كان التحديث مطلوبًا
(لن يفرض شيئًا إلى أن يُبرمج عميل التحديث).

## الأمان

SHA-256 يكشف اختلاف الملف عن البيانات المعلنة، لكنه **لا يثبت هوية الناشر**
إذا تمكن شخص من تعديل كل من الملف والبيانات. أندرويد يتحقق من تطابق توقيع
التطبيق عند التحديث؛ ولحماية بيانات التحديث نفسها مستقبلًا يلزم توقيعها
بمفتاح خاص محفوظ خارج المستودع وتضمين المفتاح العام فقط في اللعبة.
