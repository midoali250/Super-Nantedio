## 2. Emulation through the app's own JNI frontend

`tools/host/CMakeLists.txt` compiles `app/src/main/cpp/nes_jni.c` for Linux
together with the FCEUmm sources; `tools/host/drive.py` drives it with ctypes.

```
frame size 256 x 240
Player 1: Gamepad
Player 2: Zapper
emulation speed: 1976 fps (0.51 ms/frame)        # 33x faster than NTSC
audio: 799.9 samples per video frame             # 48 kHz / 60.0988 fps
```

### Duck Hunt

| step | evidence |
| --- | --- |
| boot -> multicart menu, DOWN highlights DUCK HUNT | `docs/shots/multicart-duckhunt.png` |
| START -> Duck Hunt GAME A/B/C title | `docs/shots/duckhunt-title.png` |
| one Zapper tap on the "GAME A" row starts round 1 | `docs/shots/duckhunt-round.png` |
| tapping a flying duck registers a hit (score 001000, two ducks in the HIT bar) | `docs/shots/duckhunt-hit.png` |

The gun position is delivered as `RETRO_DEVICE_ID_LIGHTGUN_SCREEN_X/Y` with the
trigger on `RETRO_DEVICE_ID_LIGHTGUN_TRIGGER`; the port is opened with
`RETRO_DEVICE_SUBCLASS(RETRO_DEVICE_MOUSE, 0)` (258), which is what FCEUmm
expects for a Zapper. `fceumm_zapper_mode=lightgun`,
`fceumm_zapper_trigger/sensor=enabled`, `fceumm_zapper_tolerance=8`.
