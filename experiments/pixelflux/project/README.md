# PixelFlux

PixelFlux is a light, single-cartridge frontend for Android, Windows, Linux and macOS, based on the shared BitVault Engine. The bundled multicart contains its own game-selection menu; the app does not duplicate that list. Start the cartridge using **Play**, then use its own menu.

Settings include display, keyboard/gamepad mappings on desktop, free-floating joystick and four movable buttons on Android, manual save/load slots, and a confirmed reset. Reset permanently removes local settings and saves; the bundled cartridge stays. **About** includes developer attribution. No update service, updater key, or GitHub credential is included.

Built from the exact Drive file verified by SHA-256; the repository is private by default. Bundled third-party core attribution is included. Hardware controller pairing is handled by the operating system. Release builds are subject to the technical and platform signing limitations documented with each artifact. The ROM contains an in-cartridge menu; its title does not independently verify that it has 1,200 unique games.
